# HACC Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-02-03

### Added

- Initial release of HACC (Home Assistant Claude Code)
- Web-based terminal interface via ttyd
- YOLO mode for auto-approved commands
- Dark and light theme support
- Full access to HA configuration directories
- Persistent SSH keys across restarts
- Support for aarch64 and amd64 architectures
- Model selection (sonnet, opus, haiku)
